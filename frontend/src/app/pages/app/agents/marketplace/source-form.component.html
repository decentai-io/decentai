What the repository needs

DecentAI reads two files and runs none of your code. One agent needs a manifest.yaml at the repository root; several need a decentai-agents.yaml catalog naming each agent's folder, with a manifest.yaml inside it.

The manifest declares what the agent can do, its functions and the permission each needs, and what it wants to keep. That declaration is exactly what an administrator approves, and approving pins the commit, so later pushes never change an install that already happened.
