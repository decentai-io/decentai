# DecentAI — the short paper

*DecentAI: Separating Proposal from Authority in Tool-Using AI Agents* —
the conference-length version of the paper: threat model, design,
security analysis, evaluation, related work and limitations, in seven
pages at 10 pt, two columns (references included). The long version,
which describes every mechanism with the file that implements it, is in
[`../arxiv`](../arxiv/README.md).

Both are typeset in the same image. From PowerShell:

```powershell
.\build.ps1
```

The PDF is `decentai-paper-8page.pdf`. Facts and numbers follow the
long version's evaluation (runs of 15 October 2026); a change to a
mechanism or a test count belongs in both.
